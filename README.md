# 🎙️ SiapInterview - AI Mock Interview & Career Copilot (B2C Micro-SaaS)

Platform simulasi wawancara kerja berbasis AI dan auditor ATS yang dirancang khusus untuk pasar B2C (pelamar kerja, fresh graduates, career switchers).

## 🌟 Fitur Utama
1. **Simulasi Wawancara Suara Nyata:** AI membacakan pertanyaan langsung via audio browser dan mendengarkan jawaban suara kandidat (Speech-to-Text).
2. **Kustomisasi Persona Pewawancara:** 
   - 👩‍💼 *Bu Rina (HRD People & Culture)*: Uji kepribadian, teamwork, dan metode STAR.
   - 👨‍💻 *Pak Dimas (User Lead)*: Kritis, teknis, uji metrik nyata dan alur kerja proyek.
   - 🇮🇩 / 🇬🇧 Dukungan Bahasa Indonesia & Bahasa Inggris.
3. **Ekstraksi CV PDF Otomatis:** Menggunakan `pypdf` untuk membaca riwayat kerja kandidat dalam hitungan detik.
4. **Audit Kata Kunci ATS:** Membandingkan kata kunci CV dengan deskripsi loker secara real-time dan memberikan peringatan kata kunci yang hilang.
5. **Evaluasi STAR & Jawaban Ideal:** Menganalisis *Situation, Task, Action, Result* serta memberikan rekomendasi jawaban impresif versi AI.
6. **Simulasi Monetisasi QRIS:** Alur pembayaran pay-as-you-go khas Micro-SaaS Indonesia (Rp19.000 untuk top-up 5 sesi) dengan simulasi pembayaran instan.

## 🚀 Cara Menjalankan
Pastikan Python 3.10+ sudah terinstal, lalu jalankan:

```bash
python run.py
```

Buka browser di:
👉 **http://localhost:8000**
